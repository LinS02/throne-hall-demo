# 沉闕城・王座之廳（試玩）

單獨可玩的 BOSS 戰試作：十字形大殿、會變身召喚分身的王座之主、第三／第一人稱、寒霜爆裂法術與道具／星盤介面。
非官方的個人同人致敬作品，與任何商業遊戲及其公司無關；場景、角色、音樂、文字皆為原創製作。

**操作需要鍵盤＋滑鼠**（點畫面鎖定滑鼠）：WASD 走、空白鍵翻滾／按住衝刺、左鍵攻擊、Shift＋左鍵重擊、W＋左鍵踢、
右鍵格擋、Shift＋右鍵彈反、R 喝藥、F 雙持／單手、Q 或中鍵鎖定、V 第一人稱、M 靜音；
技能：按住 E、T；P 星盤、I 裝備寶珠、1／2 預設配置。
